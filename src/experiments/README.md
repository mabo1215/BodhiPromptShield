## On what may be claimed as reproduced

A table with no record and no script behind it must not be described in the
paper as regenerated by this repository. Such a table is either a manually
curated result from a controlled run, or expository content, and should be read
as one of those.

Release cards and manifests bound the evidence and the reproducibility scope.
They are not benchmark results and should not be read as additional scores.

For public OCR and document benchmarks, baseline repositories, request-gated
clinical corpora and closed-model documentation, generate the current
acquisition manifest with `acquire_external_resources.py` first, then use
`ocr_external_transfer.py` to turn the OCR-heavy targets into a protocol and
availability scaffold. For the executed CORD rerun, `acquire_cord_snapshot.py`
pins the revision and `cord_ocr_transfer_suite.py` writes the wrapper, result,
runtime and run-log records. A resource becomes executed evidence in the paper
only once the wrapper is aligned, the runtime is logged, and the result files
are on disk.
