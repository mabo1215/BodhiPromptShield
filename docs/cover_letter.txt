Dear Editors,

We submit "BodhiPromptShield: Pre-Inference Prompt Mediation for Surface-Form Privacy Propagation in LLM Agent Pipelines" for consideration by Proceedings on Privacy Enhancing Technologies, Issue 3 of 2027.

The paper addresses a deployment-time privacy problem in LLM agent pipelines. Raw user content does not stay in one model call: it enters retrieval queries, memory writes, tool arguments, OCR-derived text, and logs, and every downstream copy inherits whatever the first write contained. De-identification middleware is normally designed and evaluated at a single document or ingress boundary, which does not measure this failure mode. We treat prompt privacy as a propagation-control problem across agent boundaries and evaluate it accordingly.

BodhiPromptShield is a policy-aware pre-inference mediation layer that detects sensitive spans, routes them to typed placeholders, semantic abstraction, or secure symbolic mapping, and defers exact-value restoration to authorized execution boundaries. The paper makes no cryptographic or differential-privacy claim; it is a systems and measurement contribution.

The three contributions are:

1. A propagation-control formulation with a threat-to-evaluation mapping, and a protocol that measures exposure at each agent boundary rather than once at a document boundary.
2. Restoration timing established as a measured security variable. Holding the detector and mapping fixed and moving only the point at which real values re-enter the pipeline changes boundary leakage from 51.0% [48.0, 54.0] to 1.6% [1.1, 2.1] on real agent trajectories, with disjoint intervals, for 0.11 points of task helpfulness.
3. A head-to-head comparison of ten mediation methods under one protocol on real agent data, and the surface-form-to-fact leakage gap it exposes.

The evaluation uses 300 AI4Privacy documents through a reference agent, 493 PrivacyLens agent trajectories, 200 PrivacyLens tasks scored by that benchmark's own judge model and verbatim judging prompts with a 32B open-weight agent, and AgentDojo banking tasks executed against its real sandboxed tools under prompt injection. Comparators include installed version-pinned Microsoft Presidio, a reimplemented Casper-style sanitizer, an LLM sanitizer, a GLiNER transformer PII detector, and spaCy NER. Every reported quantity carries a bootstrap confidence interval.

We draw the reviewers' attention to two negative results that the paper reports as findings rather than as caveats. First, no surface-level method measured, including ours, materially reduces factual disclosure: 83.0-98.8% of sensitive facts survive mediation on a deliberately conservative lexical criterion, and downstream judge-scored leak rates do not move. Second, mediation does not defend against prompt injection; attack success is statistically unchanged across conditions. We consider the size of the first gap, measured across methods, to be the paper's most consequential result, because it bounds what any mechanism of this class can claim.

Relevance to real-world privacy applications. The setting is one that organizations are deploying now: assistants that read a user's document, search an internal index, keep a running memory, and call tools that write to real systems. The paper gives an operator of such a system a measured account of what a mediation layer prevents - literal identifiers reaching retrieval queries, memory writes, tool arguments, and logs before an authorized boundary needs them - and what it does not. The released artifact contains the middleware, the benchmark construction and split scripts, all experiment and figure scripts, the run manifests, and the result records behind every reported number.

Prior review. This manuscript was previously reviewed by ACM Transactions on Privacy and Security (submission TOPS-2026-06-0395) and rejected on the Associate Editor's recommendation. Per the PoPETs policy on papers previously reviewed elsewhere, the Associate Editor's comments are attached together with a point-by-point response (docs/ae_response.txt). The revision was built directly against that review: the evaluation has been rebuilt on real agent stacks with reproduced comparator systems and realistic attacks, the paper-specific benchmark has been demoted to an appendix ablation surface, the in-house utility rubric has been replaced by task-native external scoring, and three claims the AE questioned did not survive the new measurements and are now reported as negative results.

This submission is original, has not been published previously, and is not under consideration elsewhere. All authors have approved the submission. The artifact is provided anonymously for review and will be released publicly under an open license upon acceptance.
