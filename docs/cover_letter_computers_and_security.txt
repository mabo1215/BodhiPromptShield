Dear Editor-in-Chief,

We submit the manuscript "What Prompt Mediation Stops in LLM Agent Pipelines, and How to Measure It" for consideration as a full-length research article in Computers & Security.

Large language model (LLM) agents read user documents, query retrieval indexes, keep persistent memory, and call tools that act on real services. User content that enters such an agent does not stay in one model call: it is copied into retrieval queries, memory entries, tool arguments, and logs, each a further place it can leak. The most widely deployed defense mediates the prompt at ingress, replacing detected sensitive spans with placeholders and restoring exact values only where an authorized tool needs them. This paper is a security measurement study of that defense: what it stops, what it does not, and whether the instruments used to score leakage can be trusted.

The study compares Microsoft Presidio, a Casper-style sanitizer, an LLM sanitizer, and our mediation layer with three detectors under one protocol, on public benchmarks (AI4Privacy, PrivacyLens, AgentDojo) scored with each benchmark's own instruments and run with open-weight agents, under an explicit threat model with trust domains and an authorized restoration boundary. Its main findings are:

1. The detector sets identifier exposure and what it costs in over-redaction. At matched retention of at least 0.96 on AI4Privacy, a small transformer trained on that source leaves 6.5% of sensitive characters exposed against 49.2-50.5% for two zero-shot detectors, a gain that does not carry to another source, and exact identifiers in an agent's generated action fall from 13.7% to 2.1-3.1% under placeholders or dummy values.
2. An agent that plans over tokens rarely writes identifiers: 2.7% of them appear in its action under deferred restoration, against 13.7% when values return before planning (-11.0 points, 95% CI [-13.3, -8.7]). For the agent, that contrast is mediation against no mediation; restoration timing decides where values re-enter.
3. In a live tool-using agent, mediating the prompt alone leaves most values that tools return in the agent's context; only mediating every read edge keeps them out, at a large cost in task success that scoped restoration partly recovers.
4. The layer's limits are specific. No detector is robust across all eight adaptive surface-form evasion families, and mediation does not stop prompt injection. A forced-choice adversary given four same-kind candidates picks 65% of removed values but 56% with no document at all, so the release adds about 9 points under the lowest-exposure detector against 42 unprotected.
5. Measuring semantic leakage needs human validation. Blind human labels show inferability falling from 98% to 25-50% under four of five annotated mediated methods, while an LLM judge and a word-overlap metric both disagree with them (Cohen's kappa 0.16 and 0.22; two human readers agree at 0.85).

We believe the work fits the scope of Computers & Security because it evaluates a deployed privacy control against adaptive adversaries inside LLM agent systems, separates what the control protects (literal identifiers in agent state) from what it only partly protects (inferable facts) and what it does not protect (the instruction channel), and gives practitioners concrete guidance on where such a control must sit and how its effect should be measured. The main rates are reported with bootstrap confidence intervals, and every table and figure can be regenerated from the released per-unit records; the code and records are publicly available, as stated in the Data availability section.

The article runs to about 11,900 words including the abstract, references, and declarations, within the journal's 12,000-word limit. The submission consists of the manuscript (LaTeX source and PDF), a Supplementary Material file that holds the extended measurements, intervals, and design tables referenced from the main text, and a highlights file.
