Dear Editor-in-Chief,

We submit the manuscript "What Prompt Mediation Stops in LLM Agent Pipelines, and How to Measure It" for consideration as a full-length research article in Computers & Security.

Large language model (LLM) agents read user documents, query retrieval indexes, keep persistent memory, and call tools that act on real services. User content that enters such an agent does not stay in one model call: it is copied into retrieval queries, memory entries, tool arguments, and logs, each a further place it can leak. The most widely deployed defense mediates the prompt at ingress, replacing detected sensitive spans with placeholders and restoring exact values only where an authorized tool needs them. This paper is a security measurement study of that defense: what it stops, what it does not, and whether the instruments used to score leakage can be trusted.

The study compares Microsoft Presidio, a Casper-style sanitizer, an LLM sanitizer, and our mediation layer with three detectors under one protocol, on public benchmarks (AI4Privacy, PrivacyLens, AgentDojo) scored with each benchmark's own instruments and run with open-weight agents, under an explicit threat model with trust domains and an authorized restoration boundary. Its main findings are:

1. The detector sets identifier exposure. Residual exposure falls to 7.4% on AI4Privacy with an in-domain detector, against 46.7-52.2% for the strongest baselines, and identifiers in a live agent's final action fall from 13.7% to 2.7-3.1% under typed placeholders.
2. Deferring restoration to the authorized tool boundary keeps identifiers out of what the agent writes (-11.0 points, 95% CI [-13.3, -8.7]).
3. In a live tool-using agent, mediating the prompt alone leaves most values that tools return in the agent's context; only mediating every read edge keeps them out.
4. Facts survive where identifiers do not: an attribute-recovery adversary recovers 64% of the values the strongest detector removed (chance 25%), no detector is robust across all eight adaptive surface-form evasion families, and mediation does not stop prompt injection.
5. Measuring semantic leakage needs human validation. Blind human labels show inferability falling from 98% to 25-50% under mediation, while an LLM judge and a word-overlap metric both disagree with them (Cohen's kappa 0.16 and 0.22; two human readers agree at 0.85).

We believe the work fits the scope of Computers & Security because it evaluates a deployed privacy control against adaptive adversaries inside LLM agent systems, separates what the control protects (literal identifiers in agent state) from what it cannot (inferable facts and the instruction channel), and gives practitioners concrete guidance on where such a control must sit and how its effect should be measured. Every reported number carries a bootstrap confidence interval and can be regenerated from the released per-unit records; the code and records are publicly available, as stated in the Data availability section.

The submission consists of the manuscript (LaTeX source and PDF), a Supplementary Material file that holds the extended measurements, intervals, and design tables referenced from the main text, and a highlights file.
